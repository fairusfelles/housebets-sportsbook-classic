# Housebets Sportsbook — Classic Edition

Clickable front-end prototype for the Housebets Contest Labs sportsbook design contest (entry #2).
Classic premium bookmaker styling: racing green, ivory, brass — five pages in the Housebets shell
(Sports home, Live, Football, Match page Arsenal v Brighton, Bet slip + My bets), singles-only USDT slip
with odds-change accept flow, suspended markets, bet placed/failed states and cash out. Sample data only.

Built with Claude assisting on design and code; hand-written HTML/CSS/JS, hosted on GitHub Pages.
